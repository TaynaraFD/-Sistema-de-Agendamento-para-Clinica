# Sistema de Agendamento para Clinica
Este projeto consiste no desenvolvimento de um sistema de agendamento para consultórios e clínicas de pequeno porte.

O sistema foi desenvolvido para auxiliar no cadastro de pacientes e profissionais, organização dos horários de atendimento e controle dos agendamentos.

A proposta é reduzir problemas comuns em processos manuais, como conflitos de horários, dificuldade para localizar informações e perda de controle sobre os atendimentos.

 # Objetivo

Desenvolver um sistema simples para organizar o processo de agendamento de consultas, permitindo cadastrar pacientes e profissionais, realizar agendamentos, visualizar a agenda, cancelar e remarcar consultas.

# Tecnologias utilizadas

Python

**Regra de agendamento**

O sistema não permite marcar uma consulta para um profissional que já possui uma consulta no mesmo dia e horário.

Também não é possível marcar uma consulta caso o paciente ou o profissional ainda não esteja cadastrado.
